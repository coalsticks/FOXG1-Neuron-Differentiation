# 🧬 FOXG1-Dependent Dysregulation of Neuron Differentiation in ASD (RNA-seq Timecourse Analysis)

## **Overview**

This project investigates transcriptomic differences between Autism Spectrum Disorder (ASD) and non-ASD samples during in vitro neuronal differentiation. The analysis is based on RNA-seq data from Mariani et al. (2015), which studies FOXG1-dependent dysregulation in GABAergic and glutamatergic neuron development.

The goal is to explore how gene expression patterns evolve over differentiation timepoints and how they differ between ASD and control conditions.

## **Dataset**

The dataset is derived from:

Mariani J. et al. (2015). FOXG1-Dependent Dysregulation of GABA/Glutamate Neuron Differentiation in Autism Spectrum Disorders.

- RNA-seq dataset: SRP047194
- Human neuronal differentiation model
- Conditions: ASD vs non-ASD
- Days in vitro: 11 and 31

## **Research Question**

How do gene expression profiles differ between ASD and non-ASD neuronal samples across differentiation timepoints?

## **Reproducibility**

This project is fully reproducible using R with the required packages mentioned in the markdown installed.

Input data:
SRP047194 RNA-seq dataset (loaded as .rds)
